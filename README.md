# Go代码变更风险可视化系统 (Code Risk Analyzer)

基于美团技术团队的代码变更风险可视化系统设计思想，针对Go语言项目的风险分析工具。

## 核心功能

### 1. 代码变更感知
- Git仓库集成,自动检测代码提交
- 精确识别变更文件、函数、代码行
- 支持分支对比和历史版本分析

### 2. Go语言特性分析
- **包依赖分析**: 识别import变更影响
- **接口实现检查**: 追踪接口定义和实现变更
- **Goroutine并发分析**: 检测并发安全风险
- **Error处理分析**: 评估错误处理完备性
- **反射使用检测**: 识别反射带来的风险

### 3. 风险评估算法
- **复杂度评分**: 圈复杂度、认知复杂度计算
- **影响面分析**: 基于调用关系图的影响范围评估
- **历史风险关联**: 结合历史Bug数据的风险预测
- **变更频率分析**: 高频变更区域识别

### 4. 可视化展示
- 调用关系图可视化
- 风险热力图
- 变更影响面树状图
- 趋势分析图表

## 快速开始

### 环境要求
- Go 1.21+
- Neo4j 5.0+
- Node.js 18+ (前端)

### 安装

```bash
# 1. 克隆项目
git clone https://github.com/sugerdaddy/go-code-risk-analyzer.git
cd go-code-risk-analyzer

# 2. 安装Go依赖
go mod download

# 3. 安装前端依赖
cd web && npm install && cd ..

# 4. 配置Neo4j数据库
# 编辑 configs/config.yaml 配置数据库连接

# 5. 启动服务
go run cmd/server/main.go
```

### 使用示例

```bash
# 分析指定Git仓库
curl -X POST http://localhost:8080/api/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "repo_path": "/path/to/your/go/project",
    "base_commit": "main",
    "target_commit": "feature-branch"
  }'

# 查看分析报告
curl http://localhost:8080/api/report/{task_id}
```

## 核心算法

### 1. 风险评分算法

```
风险分数 = α×复杂度分数 + β×影响面分数 + γ×历史风险分数 + δ×特征风险分数

其中:
- 复杂度分数: 基于圈复杂度和认知复杂度
- 影响面分数: 基于调用关系图的广度和深度
- 历史风险分数: 基于历史Bug关联
- 特征风险分数: 基于特殊代码模式识别
```

### 2. 影响面分析

使用BFS遍历调用关系图,计算:
- 直接影响: 直接调用者数量
- 间接影响: 调用链深度和广度
- 关键路径: 影响核心业务逻辑的路径

### 3. 特征识别

基于规则引擎识别:
- Goroutine泄漏风险
- 资源未释放(文件、连接)
- 空指针引用
- 并发竞态条件
- Error忽略
- Panic未捕获

## 应用场景

1. **技术方案评审**: 自动生成变更影响分析报告
2. **Code Review增强**: 高亮风险代码区域
3. **测试用例推荐**: 根据变更影响面推荐测试范围
4. **发布前风险评估**: 量化评估发布风险
5. **重构安全性评估**: 评估重构对系统的影响
